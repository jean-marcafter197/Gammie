## 🛠️ How It Works
1. Launch Gammie.
2. Use the sliders to adjust gamma, contrast, and brightness until your screen looks just right.
3. Save your settings as a preset and assign a hotkey (e.g., `Ctrl+Shift+1`).
4. Press your hotkey anytime to switch to that preset.

You can create multiple presets for different situations:
- **Daytime** — brighter, higher contrast.
- **Nighttime** — warmer, dimmer.
- **Gaming** — enhanced gamma for dark areas.
- **Design Work** — accurate colors.

## ❓ Frequently Asked Questions

**Is Gammie safe to use?**  
Yes. Gammie is a simple display adjustment tool that does not modify system files. It runs in your system tray.

**Do I need to restart my computer after using Gammie?**  
No. Changes apply immediately and reset when you close the app.

**Can I use Gammie on multiple monitors?**  
Gammie adjusts the primary display. Support for multiple monitors may be added in future updates.

**How do I reset my display to default?**  
Close Gammie or set a preset with default values (gamma 1.0, contrast 50%, brightness 50%).
